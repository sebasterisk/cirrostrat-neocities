Hi! Recently, I was part of a delegation to Thailand affiliated by the Loyola Blakefield Cyber Science and Informatics program to attend the Royal Thai Armed Forces Cyber Warrior Contest 2026. This was pretty much my first major CTF that I competed in. Alongside me were Aidan B. '27 and Teddy M '28.

Anyways, there are a handful of challenges I found interesting enough to write up about. Here's how I found a couple of the flags. Keep in mind that AI was prohibited during this competition.

artemis orbital resonance check

→ a "medium" programming challenge

Here's the scenario. The document was originally provided in Thai, but has been translated here.

Mission Control detected multiple satellites orbiting the Earth before Artemis II launched. The engineering team had to check the orbital resonance between each pair of satellites for the safety of their trajectory.

Each satellite has an orbital period T seconds and an initial phase φ degrees. The phase of the satellite at time t is:

p(t) = (φ + 360 × t / T) mod 360

A pair of satellites experiences an "orbital resonance" when their phases are separated by "less than 1 degree" (measured circularly on a 360° circle) for the first time.

Count the number of pairs of satellites that experience orbital resonance within the first 10,000 seconds. (Consider the time as integers t = 0, 1, 2, ... 10,000)


We are then provided with the orbital period T and initial phase φ for 17 satellites labeled 'A' through 'R'. These are all seemingly arbitrary positive integers.

The flag is the MD5 value of the resulting number (i.e., the amount of satellites that experience resonance).

As this is a programming challenge, my eyes are drawn specifically to the provided function p(t), a very simple function that can be implemented very easily. I open a new Python file and implement the function.

def p(phi, T, t):
    return (phi + 360 * t / T) % 360

The three parameters correspond to the three variables inside the function; it is a direct, 1-to-1 translation of the mathematical form of p(t) that is given.

What is also given is the list of T and φ values for the 17 different satellites. I could make a class or similar to represent a satellite, but because we just need to crunch numbers quickly, I simply use two lists.

Ok, we have what we know. Now, what do we actually have to do with these things? We need to count the number of occurences that the values of p(t) for a pair of two satellites have a difference of less than 1 degree in the first 10,000 seconds. Also important: we're only counting pairs for which this happens "for the first time."

With that in mind, we'll need to program the following: calculate the phase value for each satellite, check if there are any pairs in resonance (phases with a difference of less than 1 degree), write that pair down, then count the number of unique pairs at the end — so that repeat pairs are not counted (remember "for the first time").

count = 0
pairs = []

for i in range(0, 10001):
    phases = []
    for x, v in enumerate(T_arr):
        phases.append(p(phi_arr[x], v, i))

    for x, v in enumerate(phases):
        for j in range(x+1, len(phases)):
            if (abs(v - phases[j] < 1)):
                pairs.append((x,j))
    
print(len(set(pairs)))

Ok, all together now. The nested loop starting in line 12 calculates the p(t) values for each satellite, and adds it into the phases list. Then we (naïvely) check for pairs in resonance (lines 15-18), and add it to the pairs list if so — stored as a tuple. This is repeated 10,000 times.

I was initially tempted to first check if a pair exists already in the pairs list before adding it, but since we just need the end value, what we do in line 20 by casting the list into a set to remove duplicates is easier and quicker to write.

Running the program prints the final value of 153. After running it through MD5, we obtain the final flag RTARF{b3e3e393c77e35a4a3f3cbd1e429b5dc}.
